# ФантикПэй — приложение

Flutter, Android + iOS. Код — в `lib/`:

| Путь | Что |
| --- | --- |
| `core/` | Тема (цвета и шрифты из макета), API-клиент с обновлением токена, PIN (PBKDF2), форматирование |
| `data/db.dart` | Локальная база drift: копия пространства и очередь офлайн-операций |
| `data/bank.dart` | Терминал: определение игрока по касанию, операции, игры, отмена. Всё сначала применяется локально |
| `data/sync.dart` | Отправка очереди `POST /sync` и применение изменений с сервера |
| `nfc/` | Чтение и запись NDEF-ссылки и UID (nfc_manager); `DebugCardReader` — для эмулятора |
| `features/` | Экраны: вход, семья, игра (сбор игроков, терминал, итоги, PIN), детский режим |

После изменения таблиц в `lib/data/db.dart`: `dart run build_runner build`.

## Проверка на телефонах

- Android: NFC включён, карту прикладывать к центру задней панели.
- iPhone 7 и новее: при каждом чтении открывается системное окно «Поднесите карту», карту прикладывать к верхнему краю. Для сборки нужен Apple Developer-аккаунт с включённой возможностью NFC Tag Reading (entitlements уже в `ios/Runner/Runner.entitlements`).
- Карты NTAG213/215/216 с заводской разметкой NDEF. Пустую карту приложение запишет само при привязке.
