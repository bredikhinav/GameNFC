# Как протестировать ФантикПэй

Три уровня: автотесты, сервер вручную, приложение на эмуляторе и на телефоне с картами.

## 0. Что установить на компьютер

| Для чего | Что |
| --- | --- |
| Сервер | [Docker Desktop](https://www.docker.com/products/docker-desktop/) |
| Приложение | [Flutter](https://docs.flutter.dev/get-started/install) и Android Studio (Android SDK и эмулятор) |
| iPhone | Mac с Xcode и Apple Developer-аккаунт (NFC на iPhone без платного аккаунта не работает) |
| Автотесты сервера (по желанию) | [uv](https://docs.astral.sh/uv/), PostgreSQL 16, Redis |

## 1. Поднять сервер

```bash
docker compose -f docker-compose.dev.yml up --build -d
docker compose -f docker-compose.dev.yml exec api python -m app.cli seed-demo
```

`seed-demo` создаёт семью для проверки:

- вход: `demo@fantikpay.ru` / `demo12345`, PIN терминала `1234`;
- дети и карты: Маша — `DEMOMASHA01` (340 монет), Тимур — `DEMOTIMUR01` (125), Соня — `DEMOSONYA01` (60);
- лимит переводов детей — 100 в день, переводы больше 50 подтверждает родитель.

Проверка:

- http://localhost:8000/health → `{"status":"ok"}`;
- http://localhost:8000/docs — интерактивная документация API. «Authorize» не нужен: выполните `POST /api/v1/auth/login`, затем вставьте `access_token` в Authorize;
- http://localhost:8000/c/DEMOMASHA01 — страница, которая открывается, если приложить карту к чужому телефону.

Письма (код подтверждения почты, сброс пароля) пока не отправляются, а пишутся в лог:
`docker compose -f docker-compose.dev.yml logs api | grep MAIL`.

Остановить: `docker compose -f docker-compose.dev.yml down` (добавьте `-v`, чтобы стереть базу).

## 2. Приложение на эмуляторе (без карт)

```bash
cd app
flutter pub get
flutter run --dart-define=API_URL=http://10.0.2.2:8000 --dart-define=DEBUG_CARDS=true
```

`10.0.2.2` — это адрес вашего компьютера изнутри эмулятора Android. С `DEBUG_CARDS=true` вместо касания картой появляется поле, куда вводится токен карты (`DEMOMASHA01` и т. д.).

## 3. Приложение на телефоне с картами

1. Телефон и компьютер — в одной Wi-Fi сети. Узнайте IP компьютера (`ipconfig` / `ifconfig`), например `192.168.1.20`.
2. Android: включите «Режим разработчика» и «Отладку по USB», подключите кабелем и запустите:
   `flutter run --dart-define=API_URL=http://192.168.1.20:8000`
3. iPhone: откройте `app/ios/Runner.xcworkspace` в Xcode, выберите свою команду (Team) в Signing и проверьте, что есть возможность NFC Tag Reading, затем `flutter run` с тем же `API_URL`. Для HTTP без S iOS может потребовать туннель с HTTPS (например, `cloudflared tunnel --url http://localhost:8000`) — тогда в `API_URL` укажите выданный https-адрес.
4. Карты NTAG213/215/216 из магазина. Демо-токены на карты не записаны, поэтому новые карты привяжите через приложение (см. сценарий Б).

## 4. Что пройти руками

**А. Вход и семья.** Войдите демо-аккаунтом → видны трое детей с балансами → «Настройки»: PIN «задан».

**Б. Привязка карты.** Профиль ребёнка → «Привязать карту» → приложите пустую карту: приложение запишет на неё ссылку и привяжет. Приложите эту карту к другому телефону без приложения — должна открыться страница ФантикПэй.

**В. Игра.** «Новая игра» → Банк, «С обнулением», 1500 → «Собрать игроков» → приложите 2–3 карты (или «Выбрать игрока из списка») → «Начать игру».
В терминале: сумма 200 → «Оплата» → карта → экран «Списано у Маши −200», остаток 1300. Проверьте «Начислить», «Перевод» (две карты подряд), сумму 0 → показ баланса, быстрые кнопки «За круг 200».
Сумма больше баланса → экран «Не хватает монет» → «Списать всё, что есть».
«Отменить операцию» → просит PIN → баланс вернулся.
Замок в углу → PIN → выход из режима банка. «Завершить» → итоги, приз победителю → копилка победителя выросла на приз, копилки остальных не изменились.

**Г. Без интернета.** Начните игру, включите авиарежим, проведите несколько операций — на экране результата «Нет сети · отправится позже». Выключите авиарежим → через несколько секунд в «Настройки → Синхронизация» — «всё отправлено», в http://localhost:8000/docs (`GET /api/v1/sessions/{id}`) те же балансы.

**Д. Два терминала.** Войдите демо-аккаунтом на двух телефонах. Операция на одном → на втором баланс обновится после синхронизации (потяните список на вкладке «Семья» вниз).

**Е. Потерянная карта.** Профиль → карта → «Заблокировать» → в терминале эта карта даёт «Карта заблокирована», монеты остались у ребёнка. «Отвязать» → карту можно привязать другому ребёнку.

**Ж. Телефон ребёнка.** На телефоне родителя: профиль Маши → «Телефон ребёнка» → QR-код. На втором телефоне (или эмуляторе): «У меня QR-код от родителя» → отсканировать или ввести код. Видны копилка, текущая игра и история. Перевод 20 Тимуру проходит сразу. Перевод 60 → «ждёт подтверждения» → у родителя на вкладке «Семья» появляется заявка → одобрить. Переводы сверх 100 в день отклоняются.

**З. Правила.** «Настройки → Правила и начисления»: добавить «Карманные» на сегодняшний день недели. Начисление запускается раз в час; чтобы не ждать:
`docker compose -f docker-compose.dev.yml exec api python -m app.cli run-allowances`.

**Проверка целостности после всех сценариев:**
`docker compose -f docker-compose.dev.yml exec api python -m app.cli reconcile` → `problems: 0`.

## 5. Автотесты

Сервер (нужны локальные PostgreSQL и Redis, пользователь `fantik`/`fantik`, базы `fantikpay` и `fantikpay_test`; можно взять их из `docker-compose.dev.yml`, он пробрасывает порты 5432 и 6379):

```bash
cd server
uv sync
docker compose -f ../docker-compose.dev.yml exec db createdb -U fantik fantikpay_test
uv run pytest
```

Приложение:

```bash
cd app
flutter test                                              # юнит-тесты и отрисовка экранов в app/build/screens/
flutter test --dart-define=API_URL=http://localhost:8000  # плюс офлайн-сценарии против живого сервера
```

То же самое запускается в GitHub Actions на каждый push (`.github/workflows/ci.yml`).

## Если что-то не так

Пришлите: что делали, что ожидали, что увидели. Для сервера — вывод `docker compose -f docker-compose.dev.yml logs api --tail 100`, для приложения — вывод терминала, где запущен `flutter run`.
